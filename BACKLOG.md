# Бэклог «Велогонка по Одинцово»

Цель: процедурно собрать узнаваемый участок Одинцова вдоль Можайского шоссе — повторяющийся узор из типовых домов, магазинов, остановок и переходов, с достопримечательностями через равные промежутки.

## Дорожная карта по слоям

### Слой 1. Полотно
- [x] Основная дорога: три полосы, асфальт, повороты и уклоны приходят из-за горизонта
- [x] Полоса деревьев между дорогой и тротуаром, тротуар (асфальт, местами плитка)
- [x] Остановки у самой дороги, пешеходные переходы, подземные переходы
- [x] Перекрёстки; встречная полоса слева на части участков (в России движение правостороннее — менять направление правой полосы не нужно)
- [ ] **Дублёры**: односторонние проезды вдоль шоссе, отделённые газоном; въезды и выезды с дублёра
- [ ] Переходы и через дублёр, и через шоссе — рядом с остановками
- [x] Асфальт между магазинами и домами, площадки вокруг домов, дорожки к тротуару

### Слой 2. Дома
- [x] Панельки 9–16 этажей: девятиэтажка с лестничными клетками, красные и синие 9-этажки, классические 12–14, башни II-68 (16), длинные дома уступами
- [x] Расстановка: вдоль дороги, торцом, под углом, буквой V, башни уступом, дом за сквером
- [x] Ряд магазинов и ларьков во второй линии — всегда с обеих сторон, без повторов
- [ ] **Достопримечательности (5–9 штук)** — сделать детальнее и отдельно. Сейчас есть: стела, клумба с буквами, синий фитнес с куполом, храм, бизнес-центр
